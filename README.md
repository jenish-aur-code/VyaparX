# 📒 Sauda Book

A modern, responsive business management web application built with **React.js** for managing companies, items, parties, Sauda orders, payments, dispatches, bills, reports, and business profiles.

The application is designed based on the existing **Sauda Book mobile application UI/UX** and recreated as a responsive web application for both desktop and mobile devices.

---

## 🚀 Features

### 🏠 Dashboard

- Total Sauda Orders
- Current Company information
- Current Financial Year
- Item summary
- Party List
- Sauda Order List
- Create New Sauda Order
- Item List
- Sauda Dispatch
- Sauda Bill
- Quick navigation to major modules

---
